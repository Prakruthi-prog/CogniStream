
# CogniStream Project Documentation

## 1. Project Overview
CogniStream analyses developer workflow patterns using
data analytics and interactive visualisations.

## 2. Objectives
- Collect or generate activity data.
- Clean and validate records.
- Calculate focus ratio and other metrics.
- Identify descriptive trends and patterns.
- Develop an interactive dashboard.
- Document results and limitations.

## 3. Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn,
Streamlit, Git, GitHub, and VS Code.

## 4. Methodology
1. Data collection.
2. Data cleaning.
3. Exploratory data analysis.
4. Metric calculation.
5. Visualisation.
6. Dashboard development.
7. Reporting and documentation.

## 5. Key Metrics
- Focus ratio.
- Interruptions per session.
- Task switches per session.
- Self-reported workload.
- Tasks completed.

## 6. Limitations
The included dataset is synthetic.
The metrics do not directly measure mental states.
Correlation does not prove causation.

## 7. Conclusion
The project demonstrates an end-to-end data analytics
workflow, from dataset preparation to interactive
dashboard development and reporting.
