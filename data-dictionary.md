
# Data Dictionary

| Column | Description |
|---|---|
| date | Session date |
| developer_id | Simulated developer identifier |
| session_minutes | Total session duration |
| focused_minutes | Estimated focused duration |
| interruptions | Interruption count |
| task_switches | Task switching count |
| self_reported_workload | Workload rating from 1 to 5 |
| tasks_completed | Completed tasks |
| focus_ratio_pct | Focused minutes / session minutes * 100 |
